# OpenXR OBS Mirror v0.3.0 Beta 9

Beta 9 fixes an installer bug that stopped the capture layer from loading at
all. **Anyone whose capture source has never shown anything should install this
release.**

## Fixed

- **The installed layer was ignored by Windows after a fresh install.** The
  installer wrote the layer manifest as UTF-8 with a byte order mark, and the
  OpenXR loader rejects a manifest that begins with one. It then skips the layer
  silently: no error, no log entry, and a VR application that runs perfectly
  with nothing being captured. The manifest is now written as plain UTF-8.
  Installations that had been repaired by Control Center's own install path were
  unaffected, which is why the failure looked intermittent.
- **The mirror no longer shrinks the image inside an empty border.** When an
  application renders a narrower field of view than the runtime reported, the
  mirror scaled the picture down and padded the rest of the frame. It now fills
  the frame, and still crops to the headset view when an application renders
  wider than the headset shows.
- **Alternate-eye mods no longer make the recording shudder.** Mods that render
  one eye per frame, such as Luke Ross's R.E.A.L. VR, submit a viewpoint that
  swings between the eyes every frame. The layer now recognises that pattern and
  publishes one eye consistently: half the update rate, a stable image. Nothing
  changes for applications that render both eyes every frame.

## Improved

- **Control Center explains a VR application it cannot capture.** A game driving
  the headset through the Oculus or OpenVR path never loads an OpenXR API layer,
  so the capture cannot attach to it. Instead of leaving "Waiting for an OpenXR
  app" on screen, Control Center now names the application and the path it took,
  and says to switch the mod or game to the OpenXR runtime.
- **The layer log reports the mirror scale** whenever the mirrored field of view
  differs from the one the application was given.

## Install or update

Beta 5 and newer offer this update inside the app: open Control Center, choose
**Yes, update**, and it downloads, installs, and reopens itself.

To install by hand:

1. Close OBS Studio and any running OpenXR application.
2. Download and run `OpenXR-OBSMirror-0.3.0-beta.9-Setup.exe`.

The portable ZIP contains the same self-contained app and payload. Extract the
complete archive before launching it.
