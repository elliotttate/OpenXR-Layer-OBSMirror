# v0.4.0-beta.2 — OBS 32 baseline and registration checks

OBS Studio 32 is the supported baseline on Windows and Linux. Older versions
are unsupported. Builds and automated plugin tests use OBS 32.2.2.

- Keep the Windows plugin on the OBS 32.2.2 SDK and align Linux builds with it.
- Reject OBS 30/31 at module initialization with a clear update message.
- Require OBS 32 or newer SDK headers when building either plugin.
- Test the packaged Windows DLL's source registration, translated names,
  properties, and source creation/destruction on OBS 32.2.2.
- Log the Windows OBS runtime, build API, and registration size for diagnosis.
- Rebuild Windows installer/portable and Linux packages. Vulkan capture behavior
  is unchanged from beta.1.

The reported 424-versus-408-byte source registration failure occurred on
unsupported OBS 30.2.3. Update OBS to 32.2.2; beta.1 is already confirmed working
on OBS 32. This release makes that requirement explicit and adds regression
coverage for the supported runtime.

Close OBS and the VR application before installing. Add **VR Mirror Capture
(Auto: OpenXR / SteamVR)** to your scene. An existing **OpenVR Capture** source
from the separate `win-openvr` plugin does not capture VirtualDesktopXR.
Install the complete package so the locale, presets, and companion DLL are
present. Remove manually copied old plugin DLLs from OBS's application directory
before installing into the shared plugin folder to avoid duplicate plugins.

Automated tests cover source registration and Vulkan transfers, not a live
headset session. Vulkan still uses host readback. Linux remains experimental
and native-only; see `docs/LINUX.md` and `docs/VULKAN.md`. Windows binaries are
unsigned.
