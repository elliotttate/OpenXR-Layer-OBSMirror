# VDXR OBS Mirror 1.0.1

This is the lightweight VDXR-focused package tested with Virtual Desktop
Streamer 1.34.22, VDXR 1.0.10, OBS Studio 32.2.0, and Elements Divided.

## Changes from 1.0.0

- Installs the OBS native plugin into OBS 32.2.0's shared Windows plugin path.
- Automatically requests administrator approval for that one installation step.
- Removes the obsolete per-user plugin copy that caused a **Missing Plugins**
  entry in OBS.
- Adds safer validation, uninstall path checks, checksums, compatibility notes,
  and public troubleshooting guidance.

## VDXR compatibility change

OpenXR quad layers are filtered using `XrCompositionLayerQuad.eyeVisibility`
for the eye selected in OBS. This matches the behavior honored by VDXR 1.34.22
and prevents left-only or right-only UI from leaking into the other-eye mirror.

The binaries are unsigned. Verify the ZIP using `SHA256SUMS.txt` before
installation.
