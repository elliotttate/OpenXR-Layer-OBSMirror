# OpenXR OBS Mirror v0.3.0 Beta 11

Beta 11 fixes a crash on startup that could take the VR application down
before it ever reached the headset. **Install this if a game crashes at launch
while the mirror layer is enabled.**

## Fixed

- **The layer could crash the VR application during startup.** When another API
  layer sits above this one in the chain, it may resolve OpenXR functions
  through our `xrGetInstanceProcAddr`. The OpenXR loader only hands a layer its
  downstream dispatch once its own `xrCreateApiLayerInstance` has returned, so a
  layer above that resolves functions before creating the instance below it
  reaches us while we have nothing to forward to. We called through the empty
  pointer, and the application died with an access violation at address zero —
  no error, no log entry beyond the layer's own startup banner.

  Being asked before the chain exists is now answered honestly: the function is
  reported as unsupported, and the layer log names it so the layer above can be
  identified. Nothing changes for a correctly ordered chain.

- **A failed function lookup no longer reads an unwritten pointer.** When the
  runtime reported a function as unavailable, the dispatcher still read the
  output pointer the call had left untouched and wrapped whatever it found.
  Failed lookups are now passed straight back.

Both fixes are in the dispatcher generator, so regenerating the dispatch table
keeps them.

## If a game still crashes at launch

The crash above is triggered by a layer above this one calling out of order,
and this release stops us from crashing when that happens — but the layer above
still gets an answer it may not expect. Check the other OpenXR layers you have
enabled and make sure they are up to date. Layers register themselves under
`HKEY_CURRENT_USER\Software\Khronos\OpenXR\1\ApiLayers\Implicit` and
`HKEY_LOCAL_MACHINE\...`; a value of `0` means enabled.

## Install or update

Beta 5 and newer offer this update inside the app: open Control Center, choose
**Yes, update**, and it downloads, installs, and reopens itself.

To install by hand:

1. Close OBS Studio and any running OpenXR application.
2. Download and run `OpenXR-OBSMirror-0.3.0-beta.11-Setup.exe`.

The portable ZIP contains the same self-contained app and payload. Extract the
complete archive before launching it.
