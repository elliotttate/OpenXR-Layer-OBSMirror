# VDXR OBS Mirror 1.0.3

This maintenance release addresses every actionable finding from the upstream
pull-request review. The native capture binaries are unchanged from 1.0.1 and
1.0.2.

## Installation and removal safety

- Elevates only the shared OBS plugin copy/removal, while the original Windows
  user retains ownership of the per-user OpenXR layer registration.
- Verifies the layer and plugin against the SHA-256 values in
  `BUILD-INFO.json` before validation or installation succeeds.
- Activates the OpenXR layer only after all shared plugin files copy
  successfully.
- Preserves OBS install paths ending in a backslash when passing them through
  the administrator helper.
- Makes `Uninstall.ps1 -WhatIf` a non-elevating dry run.
- Removes only the exact OpenXR manifest registration and package-owned files.
- Detects the full OpenXR/SteamVR OBS Mirror package and leaves its shared
  plugin files intact.

## Build and publishing reliability

- Selects one Visual Studio installation containing both MSBuild and C++ tools.
- Requires a runnable Python 3 interpreter before starting the native build.
- Validates that CMake supports the selected Visual Studio generator.
- Uses version-specific checksum files, validates the release branch before
  repository creation, resolves and validates the Git remote, and creates the
  release tag from the pushed branch.
- Exits cleanly when interactive repository creation is declined.
- Corrects Virtual Desktop Streamer 1.34.22 / VDXR 1.0.10 version labels.

Tested with Virtual Desktop Streamer 1.34.22, VDXR 1.0.10, OBS Studio 32.2.0,
and Elements Divided. The binaries are unsigned; verify the ZIP using the
version-specific SHA-256 file before installation.
