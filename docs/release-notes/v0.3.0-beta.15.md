# OpenXR OBS Mirror v0.3.0-beta.15

Horizontal recording overscan now expands toward the center of your vision.
Selecting the right eye adds all extra width to the left; selecting the left
eye adds all extra width to the right.

## Highlights

- **Inward horizontal expansion.** Each eye's outer edge stays fixed while the
  full added width goes toward the other eye, keeping the recording closer to
  the center of your vision. Stereo capture applies this to each eye.
- **Original headset view preserved.** The runtime receives each eye's original
  FOV and matching color/depth crop. Vertical expansion still adds room above
  and below, and the existing expansion percentages keep the same image size
  and pixel cost.
- **Updated control descriptions.** Control Center and the README explain the
  direction of horizontal expansion.

## Validation

The overscan geometry passed 320 per-eye checks and 160 stereo submission
checks, including asymmetric FOVs, fixed outer edges, headset color/depth crops,
and preservation of the original headset FOV and pose.

## Install

Close OBS Studio, run `OpenXR-OBSMirror-0.3.0-beta.15-Setup.exe`, then reopen OBS
and restart the VR application. Existing eye selections and overscan settings
continue to work. This change applies to OpenXR recording overscan.
