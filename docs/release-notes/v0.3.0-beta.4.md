# OpenXR OBS Mirror v0.3.0 Beta 4

Beta 4 adds a fast live mirror preview to Control Center and makes blank-output
problems substantially easier to diagnose.

## New

- **Live Dashboard preview.** View the shared OpenXR mirror image without
  opening OBS. The preview uses GPU downsampling and pipelined readback to avoid
  stalling the capture path.
- **Large preview window.** Open the mirror in a separate, resizable window that
  stays within the Windows work area and preserves usable title-bar controls.
- **Pixel-aware diagnostics.** The preview records frame advancement, shared
  texture generation, source size and format, GPU adapter identity, sampled
  brightness, all-black frames, stale frames, and GPU-to-CPU fallback behavior.
- **Shareable support bundles.** The Diagnostics page can upload a report with
  the preview, Control Center startup, OpenXR layer, and OBS logs and copy a
  temporary share link.

## Improved

- **Better native logging.** The layer and OBS source report pipeline state,
  swapchain eligibility, producer and consumer identity, GPU-adapter mismatch,
  copy stalls, keyed-mutex timeouts, frame age, and periodic health summaries.
- **Compact Dashboard.** The complete Dashboard now fits without vertical
  scrolling, with a smaller Quick Actions panel and the live preview replacing
  Last Capture.
- **Contextual restart notice.** The sidebar warning appears only when a running
  VR application actually needs a restart after a startup-only change. It names
  the reason and clears after the producer restarts.
- **Native installation path.** Control Center performs per-user layer updates
  directly and requests elevation only when the system-wide OBS plugin must be
  installed or replaced. Windows PowerShell is no longer required by the app.
- **Safer updates.** OBS plugin replacement is blocked while OBS is using a
  different binary, while layer-only updates remain possible without disrupting
  an active OBS recording.

## Removed

- Removed **Match fullscreen effects at the FOV boundary** because it did not
  behave reliably across applications.

## Install or update

1. Close OBS Studio and any running OpenXR application when updating both native
   components.
2. Download and run `OpenXR-OBSMirror-0.3.0-beta.4-Setup.exe`.
3. Approve the Windows administrator prompt if the OBS plugin needs to be
   installed or replaced.
4. Restart OBS and the OpenXR application, then add or reuse an **OpenXR Mirror
   Capture** source.

The portable ZIP contains the same self-contained Control Center and native
payload. Extract the complete archive before launching it.
