# OpenXR OBS Mirror v0.3.0 Beta 5

Beta 5 adds automatic updating, so keeping the capture stack current no longer
requires visiting GitHub, and it widens the recording overscan range.

## New

- **Control Center updates itself.** On launch it checks GitHub for a newer
  release. If one exists, a dialog shows what changed; choosing **Yes, update**
  downloads the installer, verifies it against the release checksum, installs it
  silently, and reopens the app. Declining is remembered until the next launch.
- **The layer and OBS source install themselves.** When Control Center finds a
  newer build of the OpenXR layer or the OBS source than the one installed, it
  installs it automatically instead of asking. The OBS source waits until OBS is
  closed, because Windows will not let a running OBS release the plugin file.
- **Recording overscan now reaches 200%.** Horizontal and vertical expansion can
  be set anywhere from 100% to 200%. The layer still limits the request to what
  the active OpenXR runtime allows for swapchain sizes, and the pixel cost shown
  on the Overscan page rises steeply near the top of the range.

## Improved

- **The OpenXR layer log survives restarts.** Sessions now append to the log and
  it rotates at 5 MB instead of being erased every time any OpenXR application
  starts, so the log covering a problem is still there when it is time to share
  it.
- **Blank OBS captures explain themselves.** Both the layer log and the OBS log
  now record why a frame did or did not reach OBS: which swapchains are mirrored
  and why the others are skipped, whether the mirror and OBS are on the same GPU,
  whether the OBS source is connected, and whether the VR application is still
  feeding frames.
- **A GPU mismatch is reported directly.** When OBS renders on a different
  adapter than the VR application, both logs now say so and name both adapters,
  instead of leaving a silently blank source.
- **Diagnostics can be shared in one step.** The Diagnostics page can upload the
  layer log, the OBS log, and a system report, then copy a single link to the
  clipboard.
- **The dashboard preview is smoother.** The live mirror preview now runs at the
  full preview rate rather than being limited by the Windows timer, and it
  pauses while the window is minimized or another page is open.

## Fixed

- **HDR titles no longer fail silently.** Applications rendering above 10 bits
  per channel could not be mirrored, and nothing said so. The reason is now
  logged.
- **OBS installed outside Program Files is found.** Control Center locates OBS
  through its installation registry entry, so **Open OBS** works with a custom
  install directory. A per-user `ObsExecutable` value under
  `HKEY_CURRENT_USER\Software\OpenXR-OBSMirror` overrides the lookup.
- **Repeated failures no longer flood the logs.** Persistent conditions, such as
  a GPU mismatch or a stalled shared texture, are now reported periodically with
  a recovery message instead of on every frame.

## Install or update

Existing Beta 5 or newer installations update themselves; nothing below is
needed for them.

1. Close OBS Studio and any running OpenXR application.
2. Download and run `OpenXR-OBSMirror-0.3.0-beta.5-Setup.exe`.
3. Open Control Center to confirm the layer and OBS source report as current.

Because automatic updating ships in this release, Beta 4 and earlier do not
offer it; this update must be installed once by hand. Updates after this one are
offered inside the app.

The portable ZIP contains the same self-contained app and payload. Extract the
complete archive before launching it.
