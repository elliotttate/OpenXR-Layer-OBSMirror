# OpenXR OBS Mirror v0.3.0 Beta 6

Beta 6 fixes finding OBS when it is installed somewhere unusual, and finishes
an OBS source update on its own once OBS closes.

## Fixed

- **OBS is found in far more places.** **Open OBS** now locates OBS through a
  running `obs64` process, the OBS installation and uninstall registry entries,
  the Windows App Paths entry, and the standard folder name on every fixed
  drive. Custom install locations and drives other than C: now work.
- **A manual location can be chosen when detection fails.** If OBS still cannot
  be found, for example with a portable copy that registers nothing, **Open
  OBS** now offers to browse for `obs64.exe`. The chosen location is saved and
  used for every later launch.
- **A waiting OBS source update completes by itself.** When an update had to
  wait for OBS to close, the status stayed on *Close OBS to update* until
  **Refresh** was pressed. Control Center now notices OBS closing and finishes
  the update within a few seconds.

## Install or update

Beta 5 and newer offer this update inside the app: open Control Center, choose
**Yes, update**, and it downloads, installs, and reopens itself.

To install by hand:

1. Close OBS Studio and any running OpenXR application.
2. Download and run `OpenXR-OBSMirror-0.3.0-beta.6-Setup.exe`.

The portable ZIP contains the same self-contained app and payload. Extract the
complete archive before launching it.

## Reporting a blank capture

If the **OpenXR Mirror Capture** source appears in OBS but stays blank, the
logs added in Beta 5 now identify the cause, including a GPU mismatch between
OBS and the VR application or an unsupported swapchain format. Reproduce the
blank source, then use **Diagnostics > Upload & share logs** and include the
copied link in the report.
