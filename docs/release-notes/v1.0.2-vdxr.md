# VDXR OBS Mirror 1.0.2

This release contains the same tested native layer and OBS plugin binaries as
1.0.1. It strengthens redistribution documentation without changing capture
behavior or performance.

## Changes from 1.0.1

- Includes the complete GNU GPL version 2 license used by OBS Studio.
- Links directly to the corresponding plugin source and OBS 32.2.0 build
  source/commit.
- Adds a clear unofficial-project and non-affiliation notice.
- Clarifies that the package contains no Virtual Desktop, OBS Studio, or game
  binaries.

Tested with Virtual Desktop Streamer 1.34.22, VDXR 1.0.10, OBS Studio 32.2.0,
and Elements Divided. The binaries are unsigned; verify the ZIP using
`SHA256SUMS.txt` before installation.
