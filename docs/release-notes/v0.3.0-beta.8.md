# OpenXR OBS Mirror v0.3.0 Beta 8

Beta 8 fixes a capture that stays completely black for applications that use
mipped swapchains, which includes UEVR and other Unreal VR injectors.

## Fixed

- **Black capture with mipped swapchains.** The mirror copied each swapchain
  image with a call that does nothing unless the source and destination have
  identical descriptions, including the number of mip levels. Applications that
  request a mipped swapchain - UEVR asks for four levels - therefore published a
  texture that had never been written, so the capture was pure black even though
  the connection, frame counter and heartbeat all reported healthy. The mirror
  now copies the base mip level explicitly, for both Direct3D 11 and 12.
- **Automatic component updates no longer go backwards.** An older Control
  Center treated any installed layer that differed from its own bundled copy as
  out of date and reinstalled the older build over it, including over a newer
  release. The installed component version is now recorded and only ever moved
  forward.

## Improved

- **The layer log records the shape of the first frames.** For the first frames
  of a session the log now lists each submitted view: its swapchain, image
  rectangle, render pose, and whether the submitted field of view matches the
  one the application was given. This is what separates an alternate-eye
  renderer from an application that ignores the located view.

## Install or update

Beta 5 and newer offer this update inside the app: open Control Center, choose
**Yes, update**, and it downloads, installs, and reopens itself.

To install by hand:

1. Close OBS Studio and any running OpenXR application.
2. Download and run `OpenXR-OBSMirror-0.3.0-beta.8-Setup.exe`.

The portable ZIP contains the same self-contained app and payload. Extract the
complete archive before launching it.
